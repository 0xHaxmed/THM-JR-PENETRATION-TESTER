# Task 06: Sniper (التحليل الرياضي والتطبيقي لهجوم القناص)

---

### المرحلة أ: نص المهمة الأصلي والأسئلة (Original Task Content & Questions)

#### English Task Description
The **Sniper** attack type is the most common and versatile mode in Burp Intruder. It is designed to fuzz individual parameters or test multiple injection points sequentially using a **single payload set**.

When executing a Sniper attack:
- Burp takes the first payload from your wordlist and places it into Position 1, leaving Position 2 (and any subsequent positions) untouched at their original template values.
- It then places the second payload into Position 1, repeating this until the payload set is completely exhausted for Position 1.
- Next, Burp resets Position 1 back to its original value, moves to Position 2, and iterates through the entire payload set again from start to finish.
- This sequence continues until every defined position has been tested against every word in the payload set.

#### The Mathematical Formula:
The total number of HTTP requests generated by a Sniper attack is strictly calculated as:
$$\text{Total Requests} = \text{Number of Positions} \times \text{Number of Payloads in Set}$$

*(Note: In addition to this formula, Burp usually sends one initial baseline request before the attack begins to establish a comparison reference, but the core attack request count follows the direct multiplication rule above).*

#### الأسئلة المطروحة (Questions):
1. If you were using Sniper to fuzz three parameters in a request with a wordlist containing 100 words, how many requests would Burp Suite need to send to complete the attack? (إذا كنت تستخدم هجوم القناص Sniper لفحص ثلاثة بارامترات في طلب باستخدام قائمة كلمات تحتوي على 100 كلمة، فكم عدد الطلبات التي سيحتاج Burp Suite لإرسالها لإكمال الهجوم؟)
2. How many sets of payloads will Sniper accept for conducting an attack? (كم عدد مجموعات الحمولات التي يقبلها هجوم Sniper لتنفيذ الهجوم؟)

### المرحلة ب: التفكير التحليلي المستقل والحس الأمني (Independent Critical Thinking & OpSec)
* **المعادلة الرياضية والتحكم في الحجم (Request Budgeting):**
  * إذا كان لديك 3 مواضع (Positions) وقائمة من 100 كلمة:
    $$\text{عدد الطلبات} = 3 \times 100 = 300 \text{ طلب}$$
  * هذا يعني أن Sniper ينمو نمواً خطياً ($O(N \times M)$)، على عكس Cluster Bomb الذي ينمو نمواً أُسياً كارثياً.
  * قبول Sniper لمجموعة حمولات واحدة فقط (`1 Payload Set`) يعني أن جميع المواضع ستتلقى نفس نوع الحمولات (مثال: قائمة بحمولات SQL Injection تمر على حقول `username` و `email` و `id` بالتناوب).

---

### المرحلة ج: التلميحات والإرشادات المتدرجة (Guided Progressive Hints)
1. **التلميح الأول (المستوى التمهيدي):**
   * اضرب عدد المواضع المحددة في إجمالي عدد الكلمات في القائمة.
2. **التلميح الثاني (المستوى العملي):**
   * $3 \times 100 = 300$.
3. **التلميح الثالث (مستوى الحل المتقدم):**
   * إجابة السؤال الأول هي `300`، وإجابة السؤال الثاني هي `1`.

### المرحلة د: الحل العملي الكامل والعمق التقني (Complete Practical Solution & Technical Deep Dive)

#### التسلسل الزمني لطلبات Sniper:
بفرض وجود موضعين: `user=§admin§&role=§user§` وقائمة بكلمتين: `[test, root]`:
```text
Baseline / Template: user=admin&role=user

Position 1 (user):
- Request 1: user=test&role=user
- Request 2: user=root&role=user

Position 2 (role):
- Request 3: user=admin&role=test
- Request 4: user=admin&role=root

إجمالي الطلبات = 2 مواضع * 2 حمولات = 4 طلبات
```

#### القيود الهندسية لنمط Sniper في Burp Suite:
- يقبل فقط مجموعة حمولات واحدة (`Payload Set: 1`).
- إذا حاولت اختيار Payload Set 2 أثناء تفعيل Sniper، ستجد الخيار معطلاً تماماً.

### المرحلة هـ: الإجابة النهائية والقيم المستخرجة (Final Answer & Key Values)
* **إجابة السؤال الأول:**
  `300`
* **إجابة السؤال الثاني:**
  `1`

  $3 \times 100 = 300$ تم قبولها فوراً.
  قبول مجموعة حمولة واحدة (`1`) تم تأكيده بعلامة النجاح الخضراء.

### المرحلة ز: الخاتمة والدرس المستفاد (Key Educational Takeaway)
* هجوم Sniper يتميز بالنمو الخطي والكفاءة العالية لفحص حقول متعددة بقائمة واحدة موحدة، مما يجعله الخيار الأول لفحص الثغرات الشائعة (مثل XSS و SQLi و SSRF) عبر نقاط إدخال متعددة دون إرهاق الخادم.
