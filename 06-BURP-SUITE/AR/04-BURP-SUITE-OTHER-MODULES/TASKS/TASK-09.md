#### English Task Description
The statistical analysis generated by Burp Sequencer is divided into several detailed tabs designed to give cryptographic and mathematical transparency into the token pool:

1. **Summary Tab:**
   - **Overall result:** A broad synthesis rating (e.g., *poor*, *fair*, *good*, *excellent*).
   - **Effective entropy:** The actual calculated bits of randomness (for example, a token of 16 bytes might only yield 40 bits of effective entropy if many character positions are fixed or predictable).
   - **Reliability:** Represents the statistical significance level (e.g., 1% significance means a 99% probability that the randomness result is mathematically valid and not a sampling artifact).
   - **Sample information:** Number of tokens collected, character set size, and token length consistency.
2. **Character-level Analysis:**
   - Evaluates randomness across each character position independently.
   - Highlights if specific positions (like the first 4 characters or last 2 characters) exhibit static or sequential behavior (e.g., hex counters or static prefixes).
3. **Bit-level Analysis:**
   - Disassembles tokens into individual binary bits and tests each bit against:
     - **FIPS monobit test:** Checks if 0s and 1s appear with equal 50% probability.
     - **FIPS poker test:** Divides the bitstream into 4-bit chunks and evaluates distribution.
     - **FIPS runs test:** Evaluates the frequency of consecutive identical bits.
     - **Autocorrelation test:** Evaluates dependence between bit intervals.
