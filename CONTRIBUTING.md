# Contributing Guidelines

Thank you for your interest in contributing to the **TryHackMe Jr Penetration Tester Bilingual Knowledge Base**!

## How to Contribute:
1. **Reporting Errors & Errata:** If you notice an outdated flag, broken link, or typographical error, please open a GitHub Issue describing the finding and referencing the affected room.
2. **Improving Explanations:** We welcome pull requests that enhance beginner-friendly explanations, add clearer diagrams, or provide additional hardening guidance.
3. **Bilingual Parity:** If you update or enhance a file in `AR/`, please ensure an equivalent update is made to its counterpart in `EN/` to maintain 1:1 structural symmetry.
4. **Code & Script Submissions:** All submitted scripts must adhere to defensive and educational standards with explicit comments explaining security parameters.

---

## Code of Conduct:
Please maintain professional, respectful, and constructive communication at all times.
