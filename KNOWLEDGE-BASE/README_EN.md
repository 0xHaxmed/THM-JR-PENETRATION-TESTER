# Technical Knowledge Base & Central Wiki

---

### 📚 Overview
This directory serves as the centralized technical knowledge base and interconnected wiki derived from the **Jr Penetration Tester** curriculum.

Rather than duplicating extensive architectural or protocol breakdowns across multiple individual rooms, canonical explanations are authored here and cross-referenced throughout room tasks and writeups.

---

### 📂 Knowledge Base Structure
1. **[Glossary (GLOSSARY)](./GLOSSARY/GLOSSARY_EN.md):** Comprehensive cybersecurity dictionary with context, RFC references, and room links.
2. **Methodologies (METHODOLOGIES):** Industry penetration testing frameworks (PTES, NIST SP 800-115, OSSTMM, OWASP WSTG).
3. **Command Reference (COMMAND-REFERENCE):** Exhaustive syntax and parameter breakdowns for terminal utilities.
4. **Tools Reference (TOOLS-REFERENCE):** Architectural internals and advanced options for offensive tooling (`nmap`, `burpsuite`, `gobuster`, `ffuf`, `msfconsole`, `netcat`, `socat`).
5. **Protocols (PROTOCOLS):** Network and application protocol mechanics (TCP/IP 3-way handshake, HTTP/1.1 vs HTTP/2, DNS, SMBv1/v2/v3, Kerberos).
6. **Technical Concepts (TECHNICAL-CONCEPTS):** Operating system security primitives, memory safeguards, and access control models.
