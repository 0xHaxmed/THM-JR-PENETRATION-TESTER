### 📂 أقسام قاعدة المعرفة
1. **[المصطلحات (GLOSSARY)](file:///e:/THM-JR-PENETRATION-TESTER/KNOWLEDGE-BASE/GLOSSARY/GLOSSARY_AR.md):** قاموس شامل للمصطلحات الإنجليزية وترجمتها وشرحها العلمي وسياق استخدامها.
2. **منهجيات اختبار الاختراق (METHODOLOGIES):** معايير التقييم (PTES, NIST SP 800-115, OSSTMM, OWASP Testing Guide).
3. **مرجع الأوامر (COMMAND-REFERENCE):** أوامر لينكس وويندوز وأوامر الأدوات مع تفصيل كل وسيط (Parameter) ومخرجاته.
4. **مرجع الأدوات (TOOLS-REFERENCE):** تفكيك معماري للأدوات الهجومية (`nmap`, `burpsuite`, `gobuster`, `ffuf`, `metasploit`, `netcat`, `socat`).
5. **البروتوكولات والشبكات (PROTOCOLS):** تحليل آليات عمل البروتوكولات (TCP/IP, HTTP/S, DNS, SMB, Kerberos, SSH, FTP).
6. **المفاهيم التقنية العميقة (TECHNICAL-CONCEPTS):** الغوص في آليات الأمان (ASLR, DEP, SUID, Windows Tokens, Same-Origin Policy, CORS).
