### 2. المراجع التقنية والوثائق الرسمية

1. **NIST National Vulnerability Database (NVD):**
   * **السجل الرسمي لثغرة xz Utils:** [CVE-2024-3094 Detail](https://nvd.nist.gov/vuln/detail/CVE-2024-3094)
   * **المعلومات المدعومة:** مواصفات الباب الخلفي في liblzma وتقييم الـ CVSS v3.1 بدرجة 10.0.

2. **Linux Manual Pages — ss(8):**
   * **الرابط:** [https://man7.org/linux/man-pages/man8/ss.8.html](https://man7.org/linux/man-pages/man8/ss.8.html)
   * **المعلومات المدعومة:** مواصفات أمر Socket Statistics وبدائل netstat في حزمة iproute2.

3. **Microsoft Learn — netstat command reference:**
   * **الرابط:** [https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/netstat](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/netstat)
   * **المعلومات المدعومة:** دلالات وسائط أداة netstat في ويندوز وخاصة الوسيط `-b`.

4. **FIRST — Common Vulnerability Scoring System v3.1 Specification:**
   * **الرابط:** [https://www.first.org/cvss/v3.1/specification-document](https://www.first.org/cvss/v3.1/specification-document)
   * **المعلومات المدعومة:** الصيغ الرياضية لحساب مؤشرات الخطورة Base, Temporal, و Environmental Metrics.

5. **Shodan Search Engine Query Syntax:**
   * **الرابط:** [https://help.shodan.io/the-basics/search-query-syntax](https://help.shodan.io/the-basics/search-query-syntax)
   * **المعلومات المدعومة:** قواعد الفلترة المتقدمة (product, port, country, org, net).
