# تقييم وختام الوحدة 01: مراجعة الانتقال المعرفي (Topic Transition Recap)

---

### 📌 نظرة عامة
يمثل هذا القسم المحطة التقييمية الختامية لـ **الوحدة 01: ابدأ رحلتك في الأمن السيبراني (Start Your Cyber Security Journey)**.

يهدف التقييم إلى التأكد من أن المتعلم قد استوعب الركائز الثلاث الأساسية قبل الانتقال إلى دراسة الأطر المنهجية المتقدمة في الوحدة الثانية:
1. **الفلسفة الهجومية:** كيف يفكر المهاجم، وكيف يستغل الثغرات البسيطة لتحقيق أثر مالي أو سيطرة كاملة على النظام.
2. **الفلسفة الدفاعية:** كيف يعمل المدافعون، وكيف ترصد السجلات وأجهزة الـ SIEM آثار الهجمات، وكيف يتم عزل التهديدات النشطة.
3. **القدرات الاستخبارية والبحثية:** كيفية الوصول إلى التوثيق الدقيق وأبحاث الثغرات العالمية ومحركات البحث التخصصية.
