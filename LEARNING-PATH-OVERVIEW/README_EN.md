# Overview of the TryHackMe Jr Penetration Tester Learning Path

---

### 🎯 Mission & Educational Objectives
The **Jr Penetration Tester** pathway on TryHackMe is one of the most recognized hands-on curricula worldwide for building a comprehensive, industry-aligned foundation in offensive security and practical ethical hacking.

The path transitions practitioners from passive conceptual knowledge to executing systematic, professional penetration tests across four primary environments:
1. **Methodologies & Legal Frameworks:** Understanding the assessment lifecycle, the Lockheed Martin Cyber Kill Chain, PTES, NIST SP 800-115, and MITRE ATT&CK.
2. **Network Reconnaissance & Port Scanning:** Mastering passive and active information gathering, Nmap host discovery, stealth scanning, service versioning, and core network protocols (DNS, SMB, SNMP, HTTP).
3. **Web Application Security & Tooling:** Web architecture mapping, automated and manual content discovery, and comprehensive operational mastery of PortSwigger's Burp Suite.
4. **Web Vulnerability Exploitation:** Hands-on exploitation of critical application vulnerabilities (SQL Injection, Command Injection, Insecure Direct Object References, Authentication Bypass, Local/Remote File Inclusion, SSRF, and XSS).
5. **Vulnerability Research & Verification:** Systematically leveraging vulnerability registries (NVD, CVE), Exploit-DB, and Searchsploit to assess vulnerabilities safely.
6. **Metasploit Framework:** Architecture of MSF, exploiting unpatched services, payload engineering with `msfvenom`, and post-exploitation with Meterpreter.
7. **Privilege Escalation:** Interactive shell handling, terminal stabilization, and systematically abusing Windows/Linux misconfigurations to escalate to `root` or `SYSTEM`.
8. **Active Directory & Enterprise Networks:** Enterprise domain architectures, Kerberos/NTLM authentication mechanics, enumeration (BloodHound), and lateral movement.
