# الوحدة الثامنة: ثغرات تطبيقات الويب 2 (Web Application Vulnerabilities II)

---

## 📌 نظرة عامة على الوحدة (Module Overview)

تُركز **الوحدة الثامنة** من مسار مختبر الاختراق المبتدئ على الجوانب الأكثر تأثيراً في تطبيقات الويب الحديثة:
- الهجمات التي تستهدف **آليات المصادقة وإدارة الجلسات** وسرقة الهويات الرقمية للمستخدمين.
- الهجمات التي تنفذ من خلال **طبقة المنطق البرمجي إلى نظام الملفات ونظام التشغيل** محققة تنفيذ الأوامر عن بعد (Remote Code Execution - RCE).
- استهداف **واجهات برمجة التطبيقات (REST APIs)** التي تغذي تطبيقات الهواتف والـ Single Page Applications (SPAs).

## 🎯 الأهداف التعليمية للوحدة

1. **السيطرة على جلسات الويب:** فهم دورة حياة الجلسات الرقمية، التلاعب بـ Session IDs، واستغلال ثغرات Session Fixation و Session Hijacking.
2. **كسر دفاعات المصادقة:** فحص آليات التحقق الثنائي (2FA) واكتشاف ثغرات المنطق في آليات إعادة تعيين كلمات المرور وتجاوز ضوابط القوة الغاشمة (Rate Limiting Bypasses).
3. **الوصول لنظام الملفات والتحكم بالخادم:** استغلال ثغرات تضمين الملفات المحلية والبعيدة (LFI / RFI) واستخدام مغلفات PHP Wrappers لتحويل قراءة الملفات إلى تنفيذ أوامر كامل (RCE).
4. **حقن أوامر النظام:** السيطرة التامة على الخادم عبر حقن محارف الفصل في أوامر الـ Shell وإنشاء قنوات اتصال عكسية تفاعلية (Reverse Shells).
5. **اختراق الـ APIs:** التدقيق المنهجي لواجهات البرمجة وفق معايير OWASP API Security Top 10.
6. **حل التحدي الواقعي (Support Challenge):** تطبيق سلسلة استغلال متكاملة في بيئة صندوق أسود.
