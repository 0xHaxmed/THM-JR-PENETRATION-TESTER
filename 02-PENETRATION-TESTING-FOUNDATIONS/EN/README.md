# Module 02: Penetration Testing Foundations

---

### 📌 Module Overview
Module 02 establishes the foundational and operational core of the modernized **TryHackMe Jr Penetration Tester** path. It transitions the practitioner into end-to-end simulated client engagements across web and infrastructure domains, contextualized by standardized adversary lifecycle models (Cyber Kill Chain) and industry assessment frameworks (PTES, NIST SP 800-115).

---

### 🏛️ Module Rooms Inventory
1. [01. Guided Pentest: Web](../01-GUIDED-PENTEST-WEB/README_EN.md)
   * The RecruitX scenario: Chaining Reconnaissance ⟶ IDOR ⟶ Password Reset Flaws ⟶ File Upload Bypass (`.phtml`) ⟶ Remote Code Execution (RCE).
2. **02. Guided Pentest: Infrastructure:**
   * Infrastructure assessment lifecycle, UnrealIRCd backdoor exploitation, internal enumeration, and privilege escalation to `root`.
3. **03. Dive Into Pentesting:**
   * Ethics, professional note-taking, and quantitative risk formulation ($Risk = Threat \times Vulnerability$).
4. **04. Cyber Kill Chain:**
   * Deconstruction of Lockheed Martin's 7 adversary phases.
5. **05. Penetration Testing Frameworks:**
   * Commercial assessment standards: PTES, NIST SP 800-115, OSSTMM, and OWASP.
6. **06. Topic Transition Recap:**
   * Module 02 synthesis assessment.

---

### 🎯 Key Competencies Acquired
* Mastering **Vulnerability Chaining**: Synthesizing low-severity issues into full server compromises.
* Analyzing input validation architecture: Replacing insecure client-side restrictions and server-side blocklists with strict file extension allowlists.
* Structuring professional assessment scopes and Rules of Engagement (RoE).
