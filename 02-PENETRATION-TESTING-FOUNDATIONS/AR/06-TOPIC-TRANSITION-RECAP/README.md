# تقييم وختام الوحدة 02: مراجعة الانتقال المعرفي (Topic Transition Recap)

---

### 📌 نظرة عامة
يمثل هذا القسم المحطة الختامية التوليفية لـ **الوحدة 02: أسس وقواعد اختبار الاختراق (Penetration Testing Foundations)**.

يربط هذا التقييم المفاهيم العملية والنظرية المكتسبة عبر الغرف الخمس للموديول:
1. **اختبار اختراق الويب العملي الموجه (Guided Pentest: Web):** استيعاب ترابط وتسلسل الثغرات (Vulnerability Chaining: Recon ⟶ IDOR ⟶ Token Brute-Force ⟶ File Upload Bypass ⟶ RCE).
2. **اختبار اختراق البنية التحتية الموجه (Guided Pentest: Infrastructure):** فحص الخدمات عبر Nmap، استغلال ثغرة الباب الخلفي في UnrealIRCd (CVE-2010-2075)، تصعيد الصلاحيات عبر ملفات كلمات المرور الصريحة، وهندسة التقارير الفنية لمدراء الهندسة.
3. **الغوص في أعماق اختبار الاختراق (Dive Into Pentesting):** التمييز بين عقلية المختبر الشاملة وعقلية المهاجم الانتهازية، سياق المخاطر، أخلاقيات المهنة، واحترام النطاق، والامتناع عن التسرع في الاستغلال.
4. **سلسلة القتل السيبراني (Cyber Kill Chain):** المراحل السبع من الاستطلاع حتى تحقيق الهدف، تقنيات التسليح بالماكرو، هجمات حفرة الماء، استغلال ثغرات يوم الصفر، الاستمرارية والتمويه بـ Timestomping، وأنفاق الـ DNS.
5. **أطر ومنهجيات اختبار الاختراق (Penetration Testing Frameworks):** الموازنة بين الأطر العامة (PTES, NIST SP 800-115, OSSTMM) والأطر التخصصية (WSTG, MASTG, PCI DSS)، ومواءمة النتائج مع مصفوفة سلوكيات الخصوم MITRE ATT&CK (مثل T1190).
