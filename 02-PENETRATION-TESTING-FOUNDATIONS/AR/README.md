# الوحدة 02: أسس ومناهج اختبار الاختراق
## Module 02: Penetration Testing Foundations

---

### 📌 نظرة عامة على الوحدة
تعتبر هذه الوحدة بمثابة النواة الهندسية والمنهجية لمسار **Jr Penetration Tester** المحدث. تنقل الوحدة المتعلم من المفاهيم التجريدية إلى التطبيق العملي المقاد عبر بيئتين محاكيتين واقعيتين:
1. **اختبار اختراق تطبيقات الويب (Web Pentest):** تطبيق عملي وسيناريو متكامل لاختراق بوابة توظيف كاملة (`RecruitX`) عبر ربط سلسلة من الثغرات (Vulnerability Chaining) تبدأ من الاستطلاع حتى تنفيذ الأوامر عن بُعد (RCE).
2. **اختبار اختراق البنية التحتية (Infrastructure Pentest):** استهداف خوادم وخدمات نظام تشغيل كاملة، واستغلال أبواب خلفية، وتصعيد الصلاحيات إلى `root`.
3. **الأطر والنماذج المعيارية:** دراسة دورة حياة الهجوم عبر نموذج سلسلة القتل السيبراني (**Lockheed Martin Cyber Kill Chain**)، واستيعاب المعايير الدولية لاختبار الاختراق (**PTES**, **NIST SP 800-115**, **OSSTMM**, **OWASP**).

---

### 🏛️ الغرف المندرجة تحت هذه الوحدة
1. [01. اختبار اختراق موجه: الويب (Guided Pentest: Web)](../01-GUIDED-PENTEST-WEB/README_AR.md)
   * سيناريو RecruitX: ربط ثغرات الاستطلاع ⟵ IDOR ⟵ إعادة تعيين كلمة المرور ⟵ رفع شل `.phtml` ⟵ تحقيق RCE.
2. **02. اختبار اختراق موجه: البنية التحتية (Guided Pentest: Infrastructure):**
   * دورة اختراق خادم شبكي واقعي، استغلال ثغرة UnrealIRCd، وتصعيد الامتيازات.
3. **03. الغوص في اختبار الاختراق (Dive Into Pentesting):**
   * عقلية الفاحص، حساب المخاطر ($Risk = Threat \times Vulnerability$)، والتوثيق المهني.
4. **04. سلسلة القتل السيبراني (Cyber Kill Chain):**
   * تشريح المراحل السبعة لهجمات التهديدات المتقدمة (Recon, Weaponization, Delivery, Exploitation, Installation, C2, Actions on Objectives).
5. **05. أطر عمل اختبار الاختراق (Penetration Testing Frameworks):**
   * معايير PTES, NIST, OSSTMM, و OWASP وقواعد الاشتباك (RoE).
6. **06. مراجعة وتقييم الانتقال (Topic Transition Recap):**
   * اختبار تلخيصي ختامي لتثبيت مهارات الوحدة الثانية.

---

### 🎯 المخرجات التعليمية والعملية للوحدة
* استيعاب مفهوم **سلسلة الثغرات (Vulnerability Chaining)**: كيف تؤدي ثغرات منخفضة الخطورة (IDOR وتسريب أسماء المستخدمين) إلى كارثة أمنية حرجة (RCE).
* تطبيق إجراءات رفع الملفات الآمنة واستبدال القوائم السوداء (Blocklists) بالقوائم البيضاء الصارمة (Allowlists).
* التخطيط المهني لاختبارات الاختراق وفق معايير PTES و NIST SP 800-115.
