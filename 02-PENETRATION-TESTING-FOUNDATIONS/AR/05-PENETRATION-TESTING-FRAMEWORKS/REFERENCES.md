### 2. المراجع الرسمية والأدلة المعيارية الدولية (Primary Framework References)

1. **ISECOM OSSTMM 3.0 (Open Source Security Testing Methodology Manual):**
   * **الرابط الرسمي:** [https://www.isecom.org/OSSTMM.3.pdf](https://www.isecom.org/OSSTMM.3.pdf)
   * **المعلومات:** الدليل المرجعي لمنهجية القياس الكمي وقيم تقييم المخاطر (RAVs).

2. **OWASP Web Security Testing Guide (WSTG v4.2):**
   * **الرابط الرسمي:** [https://owasp.org/www-project-web-security-testing-guide/](https://owasp.org/www-project-web-security-testing-guide/)
   * **المعلومات:** الإطار المعياري العالمي لفحص تطبيقات الويب ومعرفات الاختبارات (مثل `WSTG-INPV`).

3. **OWASP Mobile Application Security Testing Guide (MASTG):**
   * **الرابط الرسمي:** [https://mas.owasp.org/MASTG/](https://mas.owasp.org/MASTG/)
   * **المعلومات:** المعيار الدولي لاختبار تطبيقات أجهزة الهواتف الذكية (iOS و Android).

4. **NIST Special Publication 800-115 — Technical Guide to Information Security Testing:**
   * **الرابط الرسمي:** [https://csrc.nist.gov/publications/detail/sp/800-115/final](https://csrc.nist.gov/publications/detail/sp/800-115/final)
   * **المعلومات:** الإطار الفيدرالي لمراحل الاختبار الأمني الأربعة وتدقيق الثغرات يدوياً (Target vulnerability validation).

5. **PTES (Penetration Testing Execution Standard):**
   * **الرابط الرسمي:** [http://www.pentest-standard.org/](http://www.pentest-standard.org/)
   * **المعلومات:** المعيار الميداني المتكامل لدورة حياة اختبار الاختراق المكون من 7 مراحل.

6. **MITRE ATT&CK Enterprise Matrix:**
   * **الرابط الرسمي:** [https://attack.mitre.org/](https://attack.mitre.org/)
   * **المعلومات:** مصفوفة التكتيكات والتقنيات (TTPs) ومعرف التقنية T1190 (Exploit Public-Facing Application).

7. **PCI Security Standards Council — Information Supplement: Penetration Testing Guidance:**
   * **الرابط الرسمي:** [https://www.pcisecuritystandards.org/documents/Penetration_Testing_Guidance_v1_1.pdf](https://www.pcisecuritystandards.org/documents/Penetration_Testing_Guidance_v1_1.pdf)
   * **المعلومات:** الخطوط التوجيهية لاختبار اختراق بيئات معالجة بطاقات الدفع والائتمان.

8. **Cloud Security Alliance (CSA) — Cloud Controls Matrix (CCM v4):**
   * **الرابط الرسمي:** [https://cloudsecurityalliance.org/research/cloud-controls-matrix/](https://cloudsecurityalliance.org/research/cloud-controls-matrix/)
   * **المعلومات:** مصفوفة معايير وضوابط أمان الحوسبة السحابية.
