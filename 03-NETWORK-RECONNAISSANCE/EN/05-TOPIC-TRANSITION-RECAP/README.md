# Module 03: Topic Transition Recap — Network Reconnaissance

---

### 📌 Overview
This section represents the synthesizing, culminating milestone for **Module 03: Network Reconnaissance** in the Jr Penetration Tester Learning Path.

This assessment bridges the practical and theoretical competencies mastered across the four preceding rooms:
1. **Passive Reconnaissance:** OSINT and third-party footprinting using Whois, nslookup, dig, DNSDumpster, and Shodan without sending a single probe to target infrastructure.
2. **Active Reconnaissance:** Direct endpoint interaction using ping, traceroute, telnet, and netcat, dissecting ICMP packet header mechanics and TTL-based route mapping.
3. **Protocols and Servers:** Interactive raw socket dialogues across legacy cleartext application protocols (HTTP, FTP, SMTP, POP3, IMAP) over ports 80, 21, 25, 110, and 143.
4. **Protocols and Servers 2:** Packet capture analysis using tcpdump and Wireshark, ARP poisoning/MitM mechanics via Ettercap and Bettercap, secure remote administration via SSH, and brute-force auditing using Hydra.
