# Module 03: Network Reconnaissance

---

## 📌 Module Navigation Index

Welcome to the comprehensive technical documentation for **Module 03: Network Reconnaissance** within the **Junior Penetration Tester** pathway.
Network reconnaissance represents the initial and most vital phase of any security engagement. This module equips the practitioner with foundational and advanced methodologies to map target network surfaces, identify domain records, trace routing infrastructure, and dissect the core application protocols powering the modern internet.

---

### 🏛️ Module Rooms Breakdown

1. [01. Passive Reconnaissance](file:///e:/THM-JR-PENETRATION-TESTER/03-NETWORK-RECONNAISSANCE/01-PASSIVE-RECONNAISSANCE/README_EN.md)
   * Domain ownership and registration lookup via `whois`.
   * Interrogating DNS infrastructure (A, AAAA, MX, TXT, CNAME, SOA records) using `nslookup` and `dig`.
   * Non-intrusive Open Source Intelligence (OSINT) gathering without sending packets to the target.

2. [02. Active Reconnaissance](file:///e:/THM-JR-PENETRATION-TESTER/03-NETWORK-RECONNAISSANCE/02-ACTIVE-RECONNAISSANCE/README_EN.md)
   * Network reachability, ICMP mechanics, and OS fingerprinting via Time-to-Live (TTL) using `ping`.
   * Hop-by-hop route path discovery and packet filtering analysis via `traceroute`.
   * Direct manual transport probing and service banner grabbing via `telnet` and netcat.
   * Initial web application surface probing via CLI and browser developer tools.

3. [03. Protocols and Servers](file:///e:/THM-JR-PENETRATION-TESTER/03-NETWORK-RECONNAISSANCE/03-PROTOCOLS-AND-SERVERS/README_EN.md)
   * Deep dive into Hypertext Transfer Protocol (HTTP) methods and status codes.
   * File Transfer Protocol (FTP) mechanics, active vs. passive modes, and anonymous authentication vulnerabilities.
   * Email communication protocols: outbound SMTP relaying, and inbound retrieval via POP3 and IMAP.

4. [04. Protocols and Servers 2](file:///e:/THM-JR-PENETRATION-TESTER/03-NETWORK-RECONNAISSANCE/04-PROTOCOLS-AND-SERVERS-2/README_EN.md)
   * Exploiting unencrypted cleartext transport protocols via Man-in-the-Middle (MitM) packet sniffing.
   * Cryptographic hardening: Secure Shell (SSH) architecture and key-based authentication replacing legacy Telnet.
   * Transport Layer Security (SSL/TLS), X.509 digital certificates, cipher suites, and modern encryption standards.

5. [05. Topic Transition Recap](file:///e:/THM-JR-PENETRATION-TESTER/03-NETWORK-RECONNAISSANCE/05-TOPIC-TRANSITION-RECAP/README_EN.md)
   * Cumulative synthesis and evaluation questions ensuring complete readiness before advancing to Module 04: Nmap.
