### 2. المراجع الرسمية ومعايير الإنترنت (RFC Standards & Tools)

1. **RFC 3912 — WHOIS Protocol Specification:**
   * **الرابط:** [https://www.rfc-editor.org/rfc/rfc3912](https://www.rfc-editor.org/rfc/rfc3912)
   * **المعلومات:** المواصفة المعيارية لبروتوكول استعلام تسجيل النطاقات على المنفذ 43/TCP.

2. **RFC 1035 — Domain Names - Implementation and Specification:**
   * **الرابط:** [https://www.rfc-editor.org/rfc/rfc1035](https://www.rfc-editor.org/rfc/rfc1035)
   * **المعلومات:** البنية المعمارية لسجلات الـ DNS وحزم الاستعلام والاستجابة.

3. **RFC 7480 — HTTP Usage in the Registration Data Access Protocol (RDAP):**
   * **الرابط:** [https://www.rfc-editor.org/rfc/rfc7480](https://www.rfc-editor.org/rfc/rfc7480)
   * **المعلومات:** البديل العصري لبروتوكول WHOIS المدعوم من منظمة ICANN.

4. **BIND 9 dig Documentation (ISC):**
   * **الرابط:** [https://bind9.readthedocs.io/en/latest/manpages.html#dig-dns-lookup-utility](https://bind9.readthedocs.io/en/latest/manpages.html#dig-dns-lookup-utility)
   * **المعلومات:** التوثيق الرسمي وخيارات سطر الأوامر لأداة `dig`.

5. **Shodan Help Center & Query Syntax:**
   * **الرابط:** [https://help.shodan.io/the-basics/search-query-syntax](https://help.shodan.io/the-basics/search-query-syntax)
   * **المعلومات:** الدليل المرجعي لاستعلامات البحث المتقدمة والفلاتر (`product:`, `port:`, `country:`).

6. **DNSDumpster Official Search Engine:**
   * **الرابط:** [https://dnsdumpster.com/](https://dnsdumpster.com/)
   * **المعلومات:** أداة استكشاف ورسم خرائط النطاقات الفرعية وسجلات الخوادم السلبية.
