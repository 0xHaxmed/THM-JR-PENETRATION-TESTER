# تقييم وختام الوحدة 03: مراجعة استطلاع الشبكات (Topic Transition Recap)

---

### 📌 نظرة عامة
يمثل هذا القسم المحطة الختامية التوليفية لـ **الوحدة 03: استطلاع الشبكات (Network Reconnaissance)** في مسار مختبر الاختراق للمبتدئين (Jr Penetration Tester).

يربط هذا التقييم المفاهيم العملية والنظرية المكتسبة عبر الغرف الأربع للموديول:
1. **الاستطلاع السلبي (Passive Reconnaissance):** جمع المعلومات الخارجية عبر أدوات Whois, nslookup, dig, DNSDumpster ومحركات بحث الأجهزة المتصلة Shodan دون إرسال حزمة واحدة للهدف.
2. **الاستطلاع النشط (Active Reconnaissance):** التعامل المباشر مع المنافذ والبروتوكولات عبر ping, traceroute, telnet, netcat، وفهم رؤوس حزم ICMP وميكانيكية عمل Traceroute في حساب أجهزة التوجيه (Routers).
3. **البروتوكولات والخوادم (Protocols and Servers):** التفاعل الحي مع بروتوكولات النص الصريح (HTTP, FTP, SMTP, POP3, IMAP) عبر المنفذ 80 و 21 و 25 و 110 و 143، واستيعاب أوامر البروتوكولات القياسية وأكواد استجاباتها.
4. **البروتوكولات والخوادم 2 (Protocols and Servers 2):** تحليل حركة المرور عبر tcpdump و Wireshark، رصد مخاطر التسميم وهجمات رجل في المنتصف عبر Ettercap و Bettercap، ومقارنة التشفير عبر SSH (مع التعداد بـ Hydra) ونظام DNS المشفر (DoH/DoT).
