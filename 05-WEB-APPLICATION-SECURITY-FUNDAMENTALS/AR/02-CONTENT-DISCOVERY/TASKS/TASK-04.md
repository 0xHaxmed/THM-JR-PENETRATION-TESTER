# المهمة 04: الاستخبارات مفتوحة المصدر - محركات البحث وأدوات الويب (Task 04: OSINT - Search Engines & Web Tools)

---

### 1. الوصف العام (Stage A: Original Task Overview)
تستعرض هذه المهمة تقنيات **الاستخبارات مفتوحة المصدر (OSINT)** المطبقة على تطبيقات الويب، مع التركيز على استغلال **محركات البحث عبر أوامر دورك (Google Dorking)** وأدوات كشف البصمة التقنية مثل **Wappalyzer**.

تتيح محركات البحث لمختبري الاختراق البحث في مليارات الصفحات المفهرسة مسبقاً دون إرسال حزمة بيانات واحدة مباشرة للهدف، مما يجعلها وسيلة استكشاف سلبية (Passive Discovery) بالغة القوة لكشف:
* الملفات والمستندات الحساسة المسربة (`filetype:pdf`, `filetype:env`).
* مسارات لوحات التحكم وتسجيل الدخول (`inurl:login`, `inurl:admin`).
* صفحات الأخطاء ورسائل استعلامات قواعد البيانات (`intext:"SQL syntax"`).

---

### 2. التفكير التحليلي المستقل (Stage B: Independent Analytical Thinking)

#### السؤال 1: معامل جوجل دورك لحصر النتائج في موقع محدد
* عندما يريد المختبر استكشاف محتويات موقع معين فقط (مثل `example.com`) واستبعاد كافة المواقع الأخرى من نتائج البحث:
  * يُستخدم المعامل المتخصص: **`site:`** (مثل `site:example.com inurl:admin`).

#### السؤال 2: الأداة والإضافة البرمجية لكشف تقنيات المواقع
* أداة وإضافة المتصفح الأكثر شهرة عالمياً التي تقوم بتحليل ترويسات الخادم، وهياكل الـ HTML، وملفات الجافاسكربت، والمتغيرات العامة (Global Variables) لتحديد نظام إدارة المحتوى، ولغات البرمجة، والمكتبات المشغلة للموقع هي:
  **`Wappalyzer`**.

### 3. التلميحات الموجهة (Stage C: Guided Hints)

### 4. الحل العملي المفصل (Stage D: Complete Practical Solution)

#### أمثلة أوامر Google Dorking الشائعة في اختبارات الاختراق:
```text
# حصر البحث في موقع الهدف واستخراج لوحات الإدارة
site:example.com inurl:admin OR inurl:login

# البحث عن ملفات التكوين والبيانات الحساسة المسربة
site:example.com filetype:env OR filetype:sql OR filetype:log

# كشف الصفحات الفرعية والوثائق الداخلية
site:example.com -www.example.com
```

#### دور إضافة Wappalyzer:
* بمجرد تثبيت إضافة Wappalyzer في المتصفح وزيارة أي موقع، تقوم فوراً بعرض قائمة منسدلة تكشف:
  * خادم الويب: Nginx أو Apache.
  * لغة البرمجة: PHP, Python, أو Node.js.
  * أطر العمل: Bootstrap, jQuery, React, Laravel.
