# المهمة 03: الاستكشاف اليدوي - ترويسات HTTP وبصمة أطر العمل (Task 03: Manual Discovery - Headers & Framework Stack)

---

### 1. الوصف العام (Stage A: Original Task Overview)
تستعرض هذه المهمة فحص **ترويسات استجابة بروتوكول HTTP (HTTP Response Headers)** وتحديد **بصمة إطار العمل (Framework Fingerprinting)** كجزء من عملية الاستكشاف اليدوي.

عند إرسال طلب إلى خادم الويب، يرجع الخادم مجموعة من الترويسات التي تكشف تفاصيل بنية الخادم:
* `Server:` تكشف نوع وإصدار خادم الويب (مثل `Apache/2.4.41` أو `nginx/1.18.0`).
* `X-Powered-By:` تكشف لغة البرمجة أو إطار العمل المشغل للباك إند (مثل `PHP/7.4.3` أو `Express` أو `ASP.NET`).
* **ترويسات مخصصة للتصحيح (Custom Debug Headers):** ترويسات يضيفها المطورون أثناء الاختبار (مثل `X-Debug-Token` أو ترويسة اختبارية مخصصة مثل `X-FLAG`).

بالإضافة إلى ذلك، فإن تحديد إطار العمل يقود المختبر للبحث عن توثيقه الرسمي لمعرفة:
1. المسار الافتراضي للوحة التحكم الإدارية (Default Admin Portal).
2. بيانات الاعتماد الافتراضية (Default Credentials مثل `admin:admin`).

---

### 2. التفكير التحليلي المستقل (Stage B: Independent Analytical Thinking)

#### السؤال 1: قيمة العلم في ترويسة `X-FLAG`
* باستخدام أداة `curl -I` أو `curl -v` لاستعراض ترويسات الرد فقط:
  نلاحظ وجود ترويسة غير معيارية يرجعها الخادم:
  `X-FLAG: THM{HEADER_FLAG}`
* قيمة العلم هي: **`THM{HEADER_FLAG}`**.

#### السؤال 2: علم لوحة تحكم إطار العمل وبيانات الاعتماد الافتراضية
* بالتدقيق في كود الصفحة والمصدر، نكتشف اسم إطار العمل المستخدم ورابط توثيقه الرسمي.
* يوضح التوثيق أن إطار العمل ينشئ تلقائياً مساراً إدارياً افتراضياً للتحكم.
* عند زيارة لوحة التحكم وتجربة بيانات الاعتماد الافتراضية الموثقة رسمياً في دليل التثبيت (`admin:admin` أو `admin:password`):
  يقبل الخادم الدخول فوراً ويظهر العلم التوجيهي:
  **`THM{CHANGE_DEFAULT_CREDENTIALS}`**.

### 3. التلميحات الموجهة (Stage C: Guided Hints)
* نفّذ الأمر `curl -I http://MACHINE_IP` في الطرفية واقرأ كافة الترويسات التي تبدأ بـ `X-`.
* ابحث عن مسار لوحة الإدارة لإطار العمل في توثيق النظام وسجل الدخول باستخدام بيانات المدير الافتراضية.

---

### 4. الحل العملي المفصل (Stage D: Complete Practical Solution)

#### الخطوة 1: فحص ترويسات HTTP واستخراج علم الترويسة
```bash
curl -I http://MACHINE_IP
```
المخرجات:
```http
HTTP/1.1 200 OK
Server: Apache/2.4.41 (Ubuntu)
X-FLAG: THM{HEADER_FLAG}
Content-Type: text/html; charset=UTF-8
```
قيمة العلم المستخرج من الترويسة هي: **`THM{HEADER_FLAG}`**.

#### الخطوة 2: الدخول للوحة التحكم بالبيانات الافتراضية
1. انتقل إلى لوحة الإدارة المكتشفة في إطار العمل: `http://MACHINE_IP/thm-framework-login`.
2. أدخل بيانات الدخول الافتراضية:
   * **Username:** `admin`
   * **Password:** `admin`
3. بمجرد تسجيل الدخول بنجاح، تفتح لوحة الإدارة وتعرض العلم:
   **`THM{CHANGE_DEFAULT_CREDENTIALS}`**.

   * **الإجابة:** `THM{CHANGE_DEFAULT_CREDENTIALS}`
