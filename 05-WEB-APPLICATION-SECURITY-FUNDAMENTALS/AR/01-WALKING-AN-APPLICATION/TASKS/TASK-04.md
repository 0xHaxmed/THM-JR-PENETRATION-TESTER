# المهمة 04: أدوات المطور - فاحص عناصر الـ DOM (Task 04: Developer Tools - Inspector)

---

### 1. الوصف العام (Stage A: Original Task Overview)
تستعرض هذه المهمة استخدام تبويب **فاحص العناصر (DOM Inspector)** في أدوات المطور المدمجة في المتصفح (Developer Tools)، والتي يمكن فتحها عبر الضغط على مفتاح `F12` أو الاختصار `Ctrl + Shift + I` أو بالنقر بزر الفأرة الأيمن على أي عنصر واختيار *Inspect*.

على النقيض من خيار "View Page Source" الذي يعرض الكود الثابت المستلم في أول لحظة، فإن تبويب Inspector يعرض **شجرة كائن المستند الحية (Live Document Object Model - DOM)** بعد أن قام المتصفح بتنفيذ أكواد الجافاسكربت وتطبيق قواعد وتنسيقات CSS.

يتيح فاحص العناصر للمختبر:
1. فحص أي عنصر مرئي أو مخفي في الصفحة.
2. تعديل نصوص وخصائص عناصر الـ HTML لحظياً.
3. التلاعب بقواعد الأنماط وتنسيقات CSS (مثل خصائص العرض `display`, الشفافية `opacity`, والإخفاء `visibility`).

---

### 2. التفكير التحليلي المستقل (Stage B: Independent Analytical Thinking)
* **المغالطة الأمنية في قيود جانب العميل (Client-Side Access Controls):**
  * يقع الكثير من المطورين المبتدئين في خطأ فادح عند بناء جدران الدفع (Paywalls) أو النوافذ المنبثقة الإجبارية (Modals/Overlays) لحجب المحتوى المدفوع أو المحتوى المميز؛ حيث يقومون بإرسال المحتوى الحساس كاملاً إلى متصفح المستخدم، ثم يضعون فوقه طبقة شفافة أو قناعاً برمجياً باستخدام CSS (مثل `.premium-customer-blocker` بخاصية `display: block`).
  * نظراً لأن المتصفح خاضع لسيطرة المستخدم والمختبر بنسبة 100%، فإن أي حجب يتم على جانب العميل (Client-Side) هو حجب وهمي يمكن تجاوزه في ثانية واحدة!
  * بالضغط بزر الفأرة الأيمن على جدار الدفع واختيار *Inspect*، يمكن حذف عنصر القناع نهائياً أو تغيير تنسيق النمط إلى `display: none`، فيختفي الحاجب على الفور ويكشف النص المحجوب تحته وبداخله العلم: **`THM{NOT_SO_HIDDEN}`**.

---

### 3. التلميحات الموجهة (Stage C: Guided Hints)
* تصفح المقال أو القسم المدفوع الذي يظهر فوقه حاجب اشتراك بريميوم (Paywall Blocker).
* افتح أداة الـ Inspector (`F12`) وحدد عنصر الحجب الذي يحمل الفئة (Class) المانعة للرؤية.
* احذف العنصر بالضغط على مفتاح `Delete` أو غيّر خاصية `display: block` إلى `display: none`.

---

### 4. الحل العملي المفصل (Stage D: Complete Practical Solution)

#### الخطوات العملية داخل المتصفح:
1. انتقل إلى المقال المحجوب في صفحة الأخبار: `http://MACHINE_IP/news/article`.
2. تظهر رسالة تفيد بضرورة الترقية لحساب مميز لرؤية باقي المقال (Paywall).
3. اضغط على مفتاح `F12` للانتقال إلى تبويب **Inspector / Elements**.
4. حدد وسم الـ div المسؤول عن الحجب:
   ```html
   <div class="premium-customer-blocker">
       <p>You must be a premium customer to view this content.</p>
   </div>
   ```
5. انقر بزر الفأرة الأيمن على هذا الوسم واختر **Delete Element** (أو توجه إلى تبويب *Styles* الجانبي وعطل خاصية `display: block` أو اجعلها `display: none`).
6. يتلاشى القناع فوراً، ويظهر نص المقال الكامل محتوياً على العلم:
   **`THM{NOT_SO_HIDDEN}`**.

### 7. المخرجات التعليمية والدروس المستفادة (Stage G: Educational Takeaway)
* **قاعدة معمارية صارمة:** "لا ترسل إلى المتصفح بيانات لا يحق للمستخدم رؤيتها". يجب أن تتم الرقابة والتحقق من الصلاحيات (Authorization) على خادم الويب (Server-Side) قبل إرسال كود الـ HTML للمتصفح؛ فإخفاء العناصر بالـ CSS لا يوفر أي أمان حقيقي على الإطلاق.
