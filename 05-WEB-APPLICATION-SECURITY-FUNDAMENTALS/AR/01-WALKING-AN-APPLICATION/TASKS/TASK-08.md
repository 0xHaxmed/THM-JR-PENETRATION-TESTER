### 2. التفكير التحليلي المستقل (Stage B: Independent Analytical Thinking)
* **المقارنة التكتيكية لأدوات فحص الواجهة الأمامية:**

| التبويب / الميزة | الوظيفة الأمنية الأساسية | أهم الثغرات المكتشفة من خلاله |
|---|---|---|
| **View Source (`Ctrl+U`)** | قراءة كود الـ HTML الثابت الأولي | كشف تعليقات المطورين، الروابط السرية، مسارات المجلدات، وإصدارات أطر العمل |
| **DOM Inspector (`F12`)** | فحص وتعديل شجرة العناصر الحية والـ CSS | كسر جدران الدفع الوهمية، تجاوز تعطيل الأزرار، وتعديل حقول النماذج المخفية |
| **Debugger / Sources** | تصحيح وتنقيح الجافاسكربت وتجميد الكود | تجميد الرسائل السريعة بـ Breakpoints، وفك تشفير الأكواد المضغوطة (Pretty Print) |
| **Network Monitor** | مراقبة حزم HTTP ومكالمات الـ AJAX | التقاط استجابات الـ API الحساسة، فحص ترويسات الأمان، ومراقبة مسارات الطلبات |
| **Storage / Application**| فحص الكوكيز والتخزين المحلي | تدقيق رايات الأمان (`HttpOnly`, `Secure`, `SameSite`) والتلاعب ببيانات الجلسات |
