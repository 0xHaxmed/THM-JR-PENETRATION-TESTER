# المهمة 06: أدوات المطور - مراقب حركة الشبكة (Task 06: Developer Tools - Network)

---

### 1. الوصف العام (Stage A: Original Task Overview)
تستعرض هذه المهمة استخدام تبويب **مراقب الشبكة (Network Tab)** في أدوات المطور لتتبع وتحليل كافة طلبات واستجابات بروتوكول HTTP التي تتبادلها صفحة الويب مع الخوادم في الوقت الفعلي.

في تطبيقات الويب الحديثة (Single Page Applications - SPAs)، لا يتم إعادة تحميل كامل الصفحة عند إرسال البيانات؛ بل تُستخدم تقنيات غير متزامنة مثل **AJAX** أو واجهة **Fetch API** لإرسال واستقبال البيانات في الخلفية بتنسيقات مثل JSON أو XML.

يتيح تبويب الشبكة للمختبر:
1. مراقبة مسار كافة الطلبات المستدعاة في الخلفية (XHR / Fetch Requests).
2. فحص ترويسات الطلب والاستجابة (Request & Response Headers) وأكواد الحالة (Status Codes).
3. فحص حمولة البيانات المرسلة (Payload / Request Body).
4. قراءة نصوص وبيانات الاستجابة القادمة من الخادم (Response Tab).

---

### 2. التفكير التحليلي المستقل (Stage B: Independent Analytical Thinking)
* **سيناريو التحدي المعملي:**
  * يمتلك الموقع نموذج اتصال في صفحة التواصل (`/contact`).
  * عند تعبئة النموذج والضغط على زر الإرسال، لا تتغير الصفحة ولكن تظهر رسالة شكر سريعة، مما يشير إلى أن النموذج أرسل بياناته عبر طلب خلفي (AJAX Request).
  * بفتح تبويب الشبكة (Network Tab) وتصفية الطلبات على نوع **Fetch/XHR**، نلاحظ إرسال طلب جديد إلى مسار يحمل الاسم:
    `contact-msg`
  * بالنقر على هذا الطلب وفتح تبويب **Response** لرؤية ما أرجعه الخادم رداً على رسالتنا، نجد رسالة الخادم التي تحتوي على العلم المخبأ:
    **`THM{GOT_AJAX_FLAG}`**.

---

### 3. التلميحات الموجهة (Stage C: Guided Hints)
* افتح أدوات المطور وانتقل إلى تبويب **Network**.
* انتقل إلى صفحة الاتصال بالموقع، واملأ حقول نموذج التواصل واضغط على زر الإرسال.
* ابحث في جدول الطلبات عن طلب يحمل الاسم `contact-msg` وانقر عليه.
* انظر في اللوحة الجانبية تحت تبويب **Response** لقراءة العلم.

---

### 4. الحل العملي المفصل (Stage D: Complete Practical Solution)

#### الخطوات العملية داخل المتصفح:
1. افتح صفحة الاتصال: `http://MACHINE_IP/contact`.
2. اضغط `F12` وتوجه إلى تبويب **Network**.
3. تأكد من أن التسجيل نشط (أيقونة الدائرة الحمراء مفعلة).
4. املأ حقول الاسم والبريد الإلكتروني والرسالة في نموذج الاتصال.
5. اضغط على زر **Send Message**.
6. يظهر في جدول الشبكة طلب جديد:
   * **Name:** `contact-msg`
   * **Method:** `POST`
   * **Status:** `200 OK`
   * **Type:** `fetch` أو `xhr`
7. انقر على طلب `contact-msg`، ثم افتح تبويب **Response** من اللوحة الجانبية:
   ستجد الرد يحمل رسالة نجاح متبوعة بالعلم:
   ```json
   {"status":"success","message":"Thank you for contacting us!","flag":"THM{GOT_AJAX_FLAG}"}
   ```

### 5. الإجابة النموذجية المعتمدة (Stage E: Final Answer)
* **السؤال:** What is the flag under the Response tab on the contact-msg network request?
* **الإجابة:** `THM{GOT_AJAX_FLAG}`

### 7. المخرجات التعليمية والدروس المستفادة (Stage G: Educational Takeaway)
* تبويب الشبكة هو بمثابة "بروكسي مصغر" داخل متصفحك يكشف كل ما يدور وراء الكواليس؛ فغالباً ما ترجع واجهات الـ API بيانات حساسة في استجابات الـ JSON دون أن تعرضها واجهة المستخدم المرئية، مما يجعل فحص تبويب Response كنزاً استخباراتياً ثميناً لمختبر الاختراق.
