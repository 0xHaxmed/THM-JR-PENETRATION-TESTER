# المهمة 03: فحص الكود المصدري للصفحة (Task 03: Viewing The Page Source)

---

### 1. الوصف العام (Stage A: Original Task Overview)
تستعرض هذه المهمة فحص كود الواجهة الأمامية الخام (Raw Client-Side Source Code) عبر ميزة **عرض مصدر الصفحة (View Page Source)** المتاحة في كافة المتصفحات عبر اختصار لوحة المفاتيح `Ctrl + U` أو بالنقر بزر الفأرة الأيمن واختيار *View Page Source*.

يحتوي الكود المصدري للواجهة الأمامية على لغات:
* **HTML:** هيكل وبنية الصفحة ومحتوى النصوص والروابط.
* **CSS:** ملفات التنسيق والأنماط البصرية.
* **JavaScript:** الأكواد التفاعلية ومنطق معالجة بيانات العميل.

أثناء فحص المصدر، يبحث مختبر الاختراق عن:
1. **تعليقات المطورين المهملة (HTML Comments `<!-- ... -->`):** التي غالباً ما تكشف مسارات اختبار، أو بيانات اعتماد مبدئية، أو ملاحظات برمجية حساسة.
2. **الروابط السرية المخفية (Hidden / Secret Links):** روابط موجودة في شجرة الـ HTML ولكنها غير مرئية للمستخدم العادي (مثل روابط خفية لصفحات إدارية).
3. **أخطاء تكوين استعراض المجلدات (Directory Listing):** مسارات المجلدات مثل `/assets/` التي تعرض محتويات الملفات عندما يغيب ملف الفهرس.
4. **بصمات أطر العمل والبرمجيات (Framework Identification):** معرفة اسم وإصدار إطار العمل المستخدم (مثل Bootstrap أو WordPress) للبحث عن ثغراته غير المحدثة.

---

### 2. التفكير التحليلي المستقل (Stage B: Independent Analytical Thinking)

#### السؤال 1: علم تعليقات الـ HTML
* ينسى المطورون غالباً إزالة التعليقات التجريبية قبل رفع الموقع إلى بيئة الإنتاج.
* عند فتح كود المصدر والبحث عن وسوم التعليقات `<!--`:
  نجد تعليقاً يضم العلم: **`THM{HTML_COMMENTS_ARE_DANGEROUS}`**.

#### السؤال 2: علم الرابط السري (Secret Link)
* بالتدقيق في كود الـ HTML، نجد وسم رابط `<a>` يشير إلى مسار غير معروض في القائمة المرئية للموقع (أو مخفي بنمط CSS).
* عند تتبع هذا الرابط وزيارته في المتصفح، يظهر العلم: **`THM{NOT_A_SECRET_ANYMORE}`**.

#### السؤال 3: علم استعراض المجلدات (Directory Listing)
* يرجع سبب ظهور قائمة الملفات (Directory Indexing) إلى خطأ في تكوين خادم الويب (مثل وجود خيار `Options Indexes` في Apache) مع غياب ملف `index.html`.
* عند استعراض مجلد الأصول الثابتة `/assets/`، يعرض الخادم قائمة بجميع الملفات المحفوظة فيه، ومن بينها ملف نصي يحمل العلم: **`THM{INVALID_DIRECTORY_PERMISSIONS}`**.

#### السؤال 4: علم إطار العمل والبرمجيات (Framework Flag)
* تحتوي تذييلات الصفحات (Footers) أو التعليقات في ملفات CSS/JS على إشارة لإطار العمل المستخدم ورابط لموقعه أو ملف التغييرات (Changelog/Documentation).
* بالبحث في كود الإطار البرمجي المشار إليه في المصدر، نجد العلم: **`THM{KEEP_YOUR_SOFTWARE_UPDATED}`**.

### 3. التلميحات الموجهة (Stage C: Guided Hints)
* اضغط `Ctrl + U` في المتصفح واقرأ الكود المصدري من البداية للنهاية.
* ابحث عن وسوم التعليقات `<!--` بواسطة `Ctrl + F`.
* تصفح مسار مجلد الأصول `/assets/` مباشرة في شريط العناوين.
* راجع روابط إطار العمل المذكور في أسفل الصفحة.

### 4. الحل العملي المفصل (Stage D: Complete Practical Solution)

#### الخطوات العملية لاستخراج الأعلام الأربعة:
1. **استخراج علم تعليق HTML:**
   افتح `view-source:http://MACHINE_IP` وابحث عن التعليقات:
   ```html
   <!-- Page specific JS THM{HTML_COMMENTS_ARE_DANGEROUS} -->
   ```
2. **استخراج علم الرابط السري:**
   ابحث في كود المصدر عن الروابط المخفية:
   ```html
   <p>Nothing to see here <a href="/secret-page">...</a></p>
   ```
   عند فتح الرابط `/secret-page` يظهر العلم: `THM{NOT_A_SECRET_ANYMORE}`.
3. **استخراج علم استعراض المجلدات:**
   انتقل إلى المسار: `http://MACHINE_IP/assets/`. تظهر واجهة Apache Directory Index وبداخلها ملف نصي يحتوي على: `THM{INVALID_DIRECTORY_PERMISSIONS}`.
4. **استخراج علم إطار العمل:**
   تحقق من الرابط في أسفل الموقع الذي يشير إلى إطار العمل واقرأ توثيقه أو تعليقات ملفات التنسيق: يظهر العلم `THM{KEEP_YOUR_SOFTWARE_UPDATED}`.
