# المهمة 05: الاستخبارات مفتوحة المصدر - الأرشيف الرقمي والمستودعات السحابية (Task 05: OSINT - Repositories & Archives)

---

### 1. الوصف العام (Stage A: Original Task Overview)
تستعرض هذه المهمة استغلال **الأرشيفات التاريخية للإنترنت ومستودعات الأكواد والحوسبة السحابية (Archives & Cloud Repositories)** في استكشاف المحتوى والمسارات المفقودة أو المسربة:
1. **آلة الزمن الرقمية (Wayback Machine):** أداة أرشيف الإنترنت التاريخية التي تحتفظ بنسخ ولقطات سابقة لصفحات المواقع تعود لسنوات مضت.
2. **مستودعات الأكواد العامة (Git Repositories - GitHub / GitLab):** حيث يرتكب المطورون أخطاء شائعة برفع كود مصدري يحتوي على مسارات داخلية سرية، أو مفاتيح API، أو سجل التغييرات التاريخي (Commit History).
3. **حاويات التخزين السحابي (Amazon S3 Buckets):** خوادم التخزين السحابي التابعة لأمازون ويب سيرفسز (AWS)، والتي تُستخدم لاستضافة ملفات الأصول الثابتة والنسخ الاحتياطية.

---

### 2. التفكير التحليلي المستقل (Stage B: Independent Analytical Thinking)

#### السؤال 1: عنوان موقع آلة الزمن الرقمية (Wayback Machine):
* الموقع التابع لمنظمة أرشيف الإنترنت (Internet Archive) غير الربحية والذي يتيح تصفح لقطات المواقع التاريخية القديمة هو:
  **`https://web.archive.org/`**.
* **القيمة التكتيكية:** غالباً ما يقوم مسؤولو المواقع بحذف الروابط القديمة من الصفحة الرئيسية دون حذف الملفات الفعلية من الخادم؛ فالبحث في النسخ المؤرشفة لعام 2018 أو 2020 يكشف ملفات ومسارات قديمة ما تزال تعمل حتى اليوم وتحتوي على ثغرات خطيرة!

#### السؤال 2: صيغة الروابط لحاويات التخزين السحابي Amazon S3:
* في بيئة أمازون للحوسبة السحابية (Amazon Web Services)، يتم الوصول إلى حاويات التخزين (S3 Buckets) عبر نطاقات تنتهي باللاحقة المعيارية:
  **`.s3.amazonaws.com`** (مثل `{bucket-name}.s3.amazonaws.com`).
* **القيمة التكتيكية:** استخراج اسم الموقع وفحص ما إذا كانت حاوية التخزين المقابلة مفتوحة للقراءة العامة (Publicly Accessible) يتيح تحميل النسخ الاحتياطية وملفات قواعد البيانات المسربة.

### 4. الحل العملي المفصل (Stage D: Complete Practical Solution)

#### أمثلة الاستكشاف عبر الأرشيف ومستودعات التخزين:
```bash
# استخدام أداة waybackurls لجلب كافة الروابط التاريخية المؤرشفة للموقع
waybackurls example.com | sort -u > archived-endpoints.txt

# فحص ما إذا كانت حاوية S3 الخاصة بالموقع متاحة للعامة
curl -s -I https://mycompany-assets.s3.amazonaws.com/
# إذا أعاد 200 OK بدلاً من 403 Forbidden، فالحاوية معرضة للتسريب!
```
