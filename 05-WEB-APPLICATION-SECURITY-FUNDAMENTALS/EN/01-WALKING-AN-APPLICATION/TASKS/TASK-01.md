# المهمة 01: التجول داخل التطبيق واستكشافه يدوياً (Task 01: Walking An Application)

---

### 1. الوصف العام (Stage A: Original Task Overview)
تستعرض هذه المهمة التمهيدية المفهوم الجوهري لمرحلة **التجول اليدوي داخل التطبيق (Walking An Application)**. قبل الشروع في استخدام الأدوات الآلية والماسحات الصاخبة (مثل Burp Suite Scanner أو Nikto)، يقتضي المنهج الأمني السليم قيام مختبر الاختراق بتصفح التطبيق يدوياً كمستخدم طبيعي باستخدام متصفح الويب وأدوات المطور المدمجة (Developer Tools).

يهدف التجول اليدوي إلى:
1. فهم المنطق التجاري للتطبيق (Business Logic).
2. رسم خريطة لجميع الصفحات والميزات والمسارات ونماذج الإدخال.
3. مراقبة حركة البيانات والتفاعل بين العميل والخادم في بيئة هادئة ومتحكم بها.

---

### 2. التفكير التحليلي المستقل (Stage B: Independent Analytical Thinking)
* **لماذا لا نبدأ مباشرة بتشغيل الماسحات الآلية؟**
  * الماسحات الآلية تفحص الأنماط العامة فقط وتعجز عن فهم السياق التجاري للتطبيق.
  * قد تؤدي الماسحات إلى تخريب قواعد البيانات، أو تفعيل آليات حظر الحسابات (Account Lockout)، أو إرسال آلاف الرسائل غير المرغوب فيها عبر نماذج الاتصال.
  * التجول اليدوي يكشف للمختبر زوايا خفية لا يراها الماسح، مثل تعليقات المطورين في كود HTML، ومسارات البرمجة غير المكتملة في ملفات الجافاسكربت، والثغرات في طريقة التعامل مع الجلسات المخزنة في المتصفح.

---

### 3. التلميحات الموجهة (Stage C: Guided Hints)
* ابدأ تشغيل الآلة المعملية الهدف عبر زر "Start Machine" للحصول على عنوان IP.
* افتح الموقع في متصفحك أو عبر متصفح AttackBox للبدء في تصفح أقسام الموقع المختلفة.

---

### 4. الحل العملي المفصل (Stage D: Complete Practical Solution)
تشغيل بيئة المعمل وفتح المتصفح للوصول إلى الموقع التجريبي:
```bash
# التأكد من عمل الاتصال بالهدف عبر المتصفح
curl -I http://MACHINE_IP
```

### 7. المخرجات التعليمية والدروس المستفادة (Stage G: Educational Takeaway)
* القاعدة الذهبية في أمان الويب: "استكشف بيدك قبل أن تضرب بأداتك". التجول اليدوي يمنحك الرؤية الشاملة التي تبني عليها خطة الهجوم وتحدد نقاط الضعف الأكثر قابلية للاستغلال.
