# المهمة 07: فحص الخمول والاستطلاع المتستر (Task 07: Idle/Zombie Scan)

---

### 1. الوصف العام (Stage A: Original Task Overview)
تستعرض هذه المهمة واحدة من أذكى وأقوى تقنيات فحص المنافذ في تاريخ الأمن السيبراني: **فحص الخمول (TCP Idle Scan)**، والتي تُفعّل في أداة Nmap عبر المعامل:
```bash
sudo nmap -sI ZOMBIE_IP TARGET_IP
```
ابتكر هذه التقنية الباحث الأمني **سلفاتوري سانفيليبو (Salvatore Sanfilippo - المعروف بـ Antirez)** عام 1998 ودمجها فيودور في Nmap. الميزة الفريدة والاستثنائية لفحص الخمول هي:
**"لا تخرج حزمة واحدة من عنوان IP الحقيقي لجهاز الفاحص متجهة نحو خادم الهدف!"**

تعتمد التقنية على استغلال جهاز وسيط خامل في الشبكة يُسمى **الزومبي (Zombie Host)** (مثل طابعة شبكية نادرة الاستخدام أو جهاز إنترنت أشياء قديم) لرصد التغيرات في حقل **معرف حزمة بروتوكول الإنترنت (IP ID)**.

---

### 2. التفكير التحليلي المستقل (Stage B: Independent Analytical Thinking)

#### خوارزمية فحص الخمول ومؤشر IP ID (The 3-Step IP ID Oracle):
1. **الخطوة 1: استطلاع حالة الزومبي (Probe Zombie's IP ID):**
   * يرسل الفاحص حزمة `SYN/ACK` إلى جهاز الزومبي.
   * يستغرب الزومبي وصول هذه الحزمة لاتصال غير موجود، فيرد بحزمة `RST`.
   * يستخرج الفاحص قيمة حقل `IP ID` من ترويسة حزمة الـ RST (ولتكن القيمة $31337$).
2. **الخطوة 2: فحص الهدف عبر انتحال شخصية الزومبي (Spoofing the Target):**
   * يرسل الفاحص حزمة `SYN` إلى المنفذ المستهدف على خادم الضحية، ولكن مع **تزوير عنوان المصدر ليكون عنوان الـ Zombie**!
   * **الحالة (أ): إذا كان منفذ الضحية مفتوحاً (Open):**
     * يرسل خادم الضحية حزمة `SYN/ACK` إلى الزومبي (لأنه يعتقد أن الزومبي هو من بدأ الاتصال).
     * يستلم الزومبي حزمة غير متوقعة، فيرد بإرسال حزمة `RST` إلى خادم الضحية.
     * إرسال هذه الحزمة يجعل نظام تشغيل الزومبي يزيد عداد الـ IP ID الداخلي لديه بمقدار 1 ($31338$).
   * **الحالة (ب): إذا كان منفذ الضحية مغلقاً (Closed) أو محجوباً (Filtered):**
     * يرد الضحية بـ `RST` أو يتجاهل الحزمة.
     * يستلم الزومبي حزمة RST (ويتجاهلها) أو لا يستلم شيئاً، وبالتالي **لا يرسل الزومبي أي حزم** ويبقى عداد الـ IP ID ثابتاً دون زيادة!
3. **الخطوة 3: التحقق النهائي من عداد الزومبي (Re-check Zombie):**
   * يرسل الفاحص حزمة `SYN/ACK` ثانية إلى الزومبي.
   * يستلم الفاحص حزمة `RST` جديدة وينظر في قيمة الـ `IP ID`:
     * إذا زادت القيمة بمقدار $2$ (الأولى بسبب رد الزومبي على الهدف، والثانية رداً على الفاحص) $\rightarrow$ **المنفذ مفتوح يقيناً (OPEN)**!
     * إذا زادت القيمة بمقدار $1$ فقط (رداً على الفاحص فقط) $\rightarrow$ **المنفذ مغلق أو محجوب (CLOSED / FILTERED)**!

#### الشروط الصارمة لاختيار جهاز الزومبي:
1. أن يكون عداد الـ IP ID في نظام تشغيله تصاعدياً خطياً (Incremental global IP ID sequence) وليس عشوائياً.
2. أن يكون الجهاز خاملاً تماماً (Idle) ولا يتبادل حزم بيانات مع أطراف أخرى على الشبكة أثناء الفحص لعدم تشويش القراءات.

### 3. التلميحات الموجهة (Stage C: Guided Hints)
* ابدأ المعامل بـ `-sI` متبوعاً بعنوان IP للجهاز الوسيط (الطابعة الزومبي).
* اكتب العنوان كاملاً بعد المعامل: `-sI 10.10.5.5`.

---

### 4. الحل العملي المفصل (Stage D: Complete Practical Solution)

#### صياغة الأمر الميداني:
```bash
# تنفيذ فحص الخمول باستخدام الطابعة الزومبي ذات العنوان 10.10.5.5
sudo nmap -sI 10.10.5.5 MACHINE_IP
```
عند تنفيذ هذا الأمر:
* تظهر في سجلات جدار حماية الهدف وسجلات الـ IDS كافة حزم الفحص قادمة حصرياً من عنوان الطابعة `10.10.5.5`.
* يظل عنوان المهاجم الفعلي غير مرئي وغير مسجل على الإطلاق في بيئة الهدف.

### 5. الإجابة النموذجية المعتمدة (Stage E: Final Answer)

* **الإجابة:** `-sI 10.10.5.5`
