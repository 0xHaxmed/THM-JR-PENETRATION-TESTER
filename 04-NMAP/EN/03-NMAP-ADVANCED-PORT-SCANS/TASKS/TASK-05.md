# المهمة 05: انتحال العناوين والتمويه بالعناوين الوهمية (Task 05: Spoofing and Decoys)

---

### 1. الوصف العام (Stage A: Original Task Overview)
تستعرض هذه المهمة تقنيتين متقدمتين للتمويه والتعمية على أنظمة الحماية وسجلات الخوادم أثناء فحص المنافذ:
1. **انتحال عنوان المصدر (IP Address Spoofing `-S`):** استبدال عنوان IP الحقيقي للفاحص بعنوان IP آخر مزور في ترويسة حزم IP.
2. **التمويه بالعناوين الوهمية (Decoy Scanning `-D`):** إرسال حزم الفحص من مجموعة من عناوين IP المختلفة والمتفرقة بالتزامن مع عنوان الفاحص الحقيقي، لخلط الأوراق وتضليل المحققين الجنائيين وأجهزة كشف التسلل (IDS).

---

### 2. التفكير التحليلي المستقل (Stage B: Independent Analytical Thinking)

#### معضلة انتحال عنوان المصدر (`-S`):
* عندما تضع عنوان IP منتحل (مثل `10.10.10.11`) في حزمة الفحص:
  * يرى خادم الهدف الحزمة قادمة من `10.10.10.11`.
  * عندما يرد الخادم بحزمة `SYN-ACK` أو `RST`، فإنه **يرسل الرد إلى العنوان المنتحل (`10.10.10.11`) وليس إلى جهازك الفعلي!**
  * لذلك، لا يمكنك استلام نتائج الفحص ما لم تكن قادراً على التنصت على حركة المرور الذاهبة للعنوان المنتحل (مثلاً على نفس الشبكة المحلية أو عبر التحكم في مسار التوجيه).
  * في Nmap، يشترط تشغيل الانتحال تحديد كارت الشبكة (`-e`) وتعطيل فحص الـ Ping (`-Pn`):
    `sudo nmap -e eth0 -Pn -S 10.10.10.11 MACHINE_IP`

#### العبقرية التكتيكية للفحص عبر العناوين الوهمية (`-D`):
* لحل مشكلة عدم استلام الردود في الانتحال، ابتكر فيودور (Fyodor) أسلوب **Decoys**:
  * يرسل Nmap حزمة فحص من عنوان وهمي 1، ثم حزمة من عنوان وهمي 2، وحزمة من عنوانك الحقيقي (`ME`).
  * يستقبل مسؤول الشبكة ومحلل الـ SOC في سجلات الجدار الناري 3 محاولات فحص متزامنة من 3 عناوين مختلفة.
  * يستحيل على المدافع معرفة أي عنوان هو المهاجم الحقيقي وأي العناوين مجرد أجهزة بريئة تم انتحالها، بينما يستلم جهازك الرد الخاص بحزمته الحقيقية ويكمل رسم خريطة المنافذ بنجاح!
  * صيغة المعامل لإضافة العنوانين `10.10.20.21` و `10.10.20.28` بالإضافة لعنوانك:
    **`-D 10.10.20.21,10.10.20.28,ME`**.

---

### 3. التلميحات الموجهة (Stage C: Guided Hints)
* لانتحال عنوان المصدر، استخدم المعامل المكون من الحرف الكبير `-S` متبوعاً بعنوان IP المزور.
* للتمويه بالعناوين الوهمية، استخدم المعامل `-D` متبوعاً بقائمة العناوين مفصولة بفواصل وتنتهي بكلمة `ME`.

---

### 4. الحل العملي المفصل (Stage D: Complete Practical Solution)

#### أمثلة الأوامر الميدانية:
```bash
# 1. فحص الهدف منتحلاً عنوان IP المصدر 10.10.10.11
sudo nmap -e tun0 -Pn -S 10.10.10.11 MACHINE_IP

# 2. فحص الهدف باستخدام عنوانين وهميين بالإضافة لعنوان جهازك
sudo nmap -D 10.10.20.21,10.10.20.28,ME MACHINE_IP

# 3. توليد 5 عناوين وهمية عشوائية تلقائياً بواسطة Nmap
sudo nmap -D RND:5,ME MACHINE_IP
```

### 5. الإجابات النموذجية المعتمدة (Stage E: Final Answers)
1. **السؤال 1:** What do you need to add to the command sudo nmap MACHINE_IP to make the scan appear as if coming from the source IP address 10.10.10.11 instead of your IP address?
   * **الإجابة:** `-S 10.10.10.11`
2. **السؤال 2:** What do you need to add to the command sudo nmap MACHINE_IP to make the scan appear as if coming from the source IP addresses 10.10.20.21 and 10.10.20.28 in addition to your IP address?
   * **الإجابة:** `-D 10.10.20.21,10.10.20.28,ME`
