# Module 04: Topic Transition Recap — Advanced Network & Port Auditing (Nmap)

---

### 📌 Overview
This section represents the culminating synthesizing milestone for **Module 04: Nmap** in the Jr Penetration Tester Learning Path.

This assessment bridges the practical and architectural competencies mastered across the four preceding technical rooms:
1. **Nmap Live Host Discovery:** Local Layer 2 ARP probing versus routed Layer 3/4 host discovery (ICMP Echo, Timestamp, Address Mask, TCP SYN/ACK, UDP), dissecting raw socket requirements versus unprivileged Berkeley sockets.
2. **Nmap Basic Port Scans:** The mechanics of Nmap's Six Port States, full three-way handshake TCP Connect scans (`-sT`), half-open stealth SYN scans (`-sS`), and connectionless UDP port auditing (`-sU`) governed by kernel ICMP rate limits.
3. **Nmap Advanced Port Scans:** Exploiting RFC 793 anomalies through Null (`-sN`), FIN (`-sF`), and Xmas (`-sX`) scans, mapping firewall boundaries with ACK scans (`-sA`), attribution obfuscation via Decoys (`-D`), IP packet fragmentation (`-ff`), and blind zero-attribution Idle/Zombie scanning (`-sI`).
4. **Nmap Post Port Scans:** Dynamic service and version detection (`-sV`), remote OS stack heuristic fingerprinting (`-O`), Nmap Scripting Engine (NSE) automation, and multi-format evidence reporting (`-oA`).
