# المهمة 06: الخلاصة والربط المعماري (Task 06: Summary)

---

### 1. الوصف العام (Stage A: Original Task Overview)
تختتم هذه المهمة الغرفة بتقديم جدول مرجعي وتلخيصي شامل لكافة تقنيات ما بعد فحص المنافذ: كشف الخدمات وإصداراتها (`-sV`)، بصمة نظام التشغيل (`-O`)، محرك السكربتات البرمجية (`NSE / -sC`)، وخيارات تصدير وحفظ التقارير (`-oA`)، مؤكدة جاهزية المختبر للانتقال إلى تقييم الانتقال المعرفي ومراجعة الوحدة الرابعة.

---

### 2. التفكير التحليلي المستقل (Stage B: Independent Analytical Thinking)
* **المصفوفة التكتيكية لما بعد فحص المنافذ (Post Port Scanning Reference Matrix):**

| الميزة / المعامل | الوظيفة التكتيكية | متطلبات الصلاحية | الاستخدام الميداني النموذجي |
|---|---|---|---|
| `-sV` | كشف الخدمات وأرقام الإصدارات | متاح للجميع (Connect) | استخراج أسماء البرمجيات والبحث عن الثغرات |
| `--version-light` | فحص خدمات خفيف وسريع (الشدة 2) | متاح للجميع | مسح شبكات ضخمة في وقت محدود |
| `--version-all` | فحص خدمات معمق وتفصيلي (الشدة 9) | متاح للجميع | استنطاق الخدمات الشاذة والمعقدة |
| `-O` | كشف بصمة نظام التشغيل ونواته | يتطلب Root (Raw Sockets) | توجيه حمولات الاستغلال واستراتيجيات تصعيد الصلاحيات |
| `--osscan-limit` | تخطي فحص النظام للأهداف غير الواعدة | يتطلب Root | تجنب إضاعة الوقت على أجهزة دون منافذ مفتوحة ومغلقة |
| `--osscan-guess` | تخمين النظام عند غياب التطابق التام | يتطلب Root | توفير أفضل تخمين للأجهزة المحمية جزئياً |
| `--traceroute` | تتبع القفزات الشبكية للهدف | يتطلب Root | رسم طوبولوجيا الشبكة وتحديد مسار التوجيه |
| `-sC` | تشغيل سكربتات NSE الافتراضية | متاح للجميع | فحص آمن وشامل للإعدادات الافتراضية للخدمات |
| `--script <name>` | تشغيل سكربت أو فئة محددة من NSE | متاح بحسب السكربت | تدقيق ثغرات محددة مثل ثغرات الويب والـ SMB |
| `-A` | الفحص الهجومي المجمع (`-sV -O -sC --traceroute`)| يتطلب Root | تجميع كافة المعلومات دفعة واحدة في تقرير واحد |
| `-oA <basename>` | حفظ التقارير بجميع الصيغ (.nmap, .gnmap, .xml)| متاح للجميع | الممارسة المعيارية الإلزامية لتوثيق الأدلة |
