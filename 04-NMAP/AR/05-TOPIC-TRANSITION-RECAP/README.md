# تقييم وختام الوحدة 04: مراجعة فحص الشبكات واستكشاف المنافذ (Topic Transition Recap)

---

### 📌 نظرة عامة
يمثل هذا القسم المحطة الختامية التوليفية لـ **الوحدة 04: فحص الشبكات واستكشاف المنافذ المتقدم (Nmap)** في مسار مختبر الاختراق للمبتدئين (Jr Penetration Tester).

يربط هذا التقييم المفاهيم العملية والنظرية المكتسبة عبر غرف الموديول الأربع:
1. **اكتشاف الأجهزة النشطة (Nmap Live Host Discovery):** التفريق بين الاستكشاف المحلي عبر ARP والاستكشاف الموجه عبر ICMP (بأنواعه الثلاثة) و TCP/UDP Pings، وفهم قيود الصلاحيات بين مآخذ النظام والمآخذ الخام.
2. **فحص المنافذ الأساسي (Nmap Basic Port Scans):** تشريح حالات المنافذ الست في Nmap، وتدفق حزم المصافحة الكاملة في Connect Scan (`-sT`)، والتخفي في SYN Scan (`-sS`)، وتحديات فحص بروتوكول UDP عديم الاتصال (`-sU`) مع تقييد رسائل أخطاء ICMP.
3. **فحص المنافذ المتقدم والتخفي (Nmap Advanced Port Scans):** استغلال ثغرات معيار RFC 793 في فحوصات Null و FIN و Xmas، ورسم قواعد الجدران النارية بـ ACK Scan، والتمويه بالـ Decoys، وتجزئة الحزم (`-f/-ff`)، وفحص الخمول الأعمى (Idle/Zombie Scan) مستعيناً بمؤشر IP ID لطابعة خاملة.
4. **ما بعد فحص المنافذ ومحرك السكربتات (Nmap Post Port Scans):** استنطاق الخدمات والإصدارات (`-sV`)، وبصمة نظام التشغيل (`-O`)، وتشغيل سكربتات محرك NSE بلغة Lua، وتصدير التقارير الهيكلية بجميع الصيغ (`-oA`).
