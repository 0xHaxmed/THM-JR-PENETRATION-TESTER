# المهمة 03: رايات مكدس بروتوكول TCP (Task 03: TCP Flags)

---

### 1. الوصف العام (Stage A: Original Task Overview)
تتعمق هذه المهمة في تشريح ترويسة بروتوكول التحكم في الإرسال **TCP Header** وفقاً للمعيار القياسي RFC 793، مع التركيز على **الرايات التحكمية الست (Control Bits / TCP Flags)** التي تتحكم في دورة حياة الجلسة، بدء الاتصال، وإنهائه.

يبلغ الحد الأدنى لحجم ترويسة TCP حوالي 20 بايتاً، وتتضمن في البايت الثالث عشر والرابع عشر 6 بتات تحكمية رئيسية:
1. **`URG` (Urgent):** إشارة إلى وجود بيانات عاجلة ذات أولوية يجب معالجتها فوراً دون انتظار في طابور التخزين المؤقت.
2. **`ACK` (Acknowledgment):** تأكيد استلام البيانات ويشير إلى أن حقل رقم التأكيد (Acknowledgment Number) يحمل قيمة صحيحة.
3. **`PSH` (Push):** طلب تمرير البيانات فوراً إلى طبقة التطبيق دون تأخير.
4. **`RST` (Reset):** إعادة تعيين الاتصال وقطع الجلسة فوراً عند حدوث خطأ أو رفض اتصال غير مرغوب فيه.
5. **`SYN` (Synchronize):** مزامنة الأرقام التسلسلية؛ وهي الراية الأولى والإلزامية لبدء أي اتصال TCP جديد (المصافحة الثلاثية).
6. **`FIN` (Finish):** إنهاء الاتصال بشكل تدريجي ولطيف (Graceful Teardown) عندما يفرغ الطرف من إرسال البيانات.

### 2. التفكير التحليلي المستقل (Stage B: Independent Analytical Thinking)

#### ديناميكية المصافحة الثلاثية (TCP 3-Way Handshake):
* كيف يؤسس جهازان اتصالاً موثوقاً عبر TCP؟
  1. **الخطوة الأولى:** يرسل العميل حزمة تحمل راية **`SYN`** فقط مع رقم تسلسلي عشوائي مبدئي (Initial Sequence Number - ISN).
  2. **الخطوة الثانية:** يرد الخادم بحزمة تحمل رايتي **`SYN, ACK`** (تأكيد استلام رقم العميل ومزامنة رقمه الخاص).
  3. **الخطوة الثالثة:** يرد العميل بحزمة تحمل راية **`ACK`**، وبهذا يكتمل تأسيس المسار وتدخل الجلسة في حالة `ESTABLISHED`.

#### دور راية الـ Reset (`RST`):
* إذا أرسل العميل حزمة `SYN` إلى منفذ مغلق، فإن النواة لا تستطيع إنشاء اتصال، فترد فوراً بحزمة تحمل راية **`RST`** (أو `RST, ACK`) لرفض الاتصال وإبلاغ العميل بعدم المحاولة مجدداً.
* كما تُستخدم `RST` لإنهاء الاتصال المفاجئ دون المرور بمرحلة `FIN` الطويلة.

### 3. التلميحات الموجهة (Stage C: Guided Hints)

* تذكر الراية المستخدمة في الحزمة الأولى لبدء المصافحة ومزامنة الأرقام التسلسلية المشتقة من كلمة "Synchronize".

### 4. الحل العملي المفصل (Stage D: Complete Practical Solution)
يمكن مراقبة هذه الرايات عملياً عبر أداة `tcpdump` أثناء استكشاف الاتصالات:
```text
# حزمة بدء الاتصال الأولى (SYN):
IP client.45321 > server.80: Flags [S], seq 184729103, win 64240, length 0

# حزمة الرد بالرفض من منفذ مغلق (RST):
IP server.80 > client.45321: Flags [R.], seq 0, ack 184729104, win 0, length 0
```
توضح الرموز في Tcpdump:
* `[S]` = راية SYN.
* `[R]` أو `[R.]` = راية RST.
* `[.]` = راية ACK.
* `[F]` = راية FIN.

### 5. الإجابات النموذجية المعتمدة (Stage E: Final Answers)
1. **السؤال 1:** What 3 letters represent the Reset flag?
   * **الإجابة:** `RST`
2. **السؤال 2:** Which flag needs to be set when you initiate a TCP connection (first packet of TCP 3-way handshake)?
   * **الإجابة:** `SYN`
