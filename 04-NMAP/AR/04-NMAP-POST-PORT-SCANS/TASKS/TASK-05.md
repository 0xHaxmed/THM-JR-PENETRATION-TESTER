# المهمة 05: حفظ المخرجات وتوثيق الأدلة (Task 05: Saving the Output)

---

### 1. الوصف العام (Stage A: Original Task Overview)
تستعرض هذه المهمة خيارات تصدير وحفظ تقارير الفحص في أداة Nmap. في اختبارات الاختراق الاحترافية، لا يجوز الاكتفاء بمشاهدة النتائج على شاشة الطرفية؛ بل يجب حفظ وتوثيق كافة المخرجات كأدلة قانونية (Legal Proof of Work) ولتمكين المعالجة الآلية وتغذية الأدوات الأخرى.

توفر Nmap أربع صيغ حفظ رئيسية:
1. **الصيغة العادية (Normal Output `-oN`):** ملف نصي عادي مطابق لما يظهر على الشاشة وسهل القراءة البشرية.
2. **صيغة المعالجة والفلترة (Greppable Output `-oG`):** ملف مصمم ليكون كل جهاز في سطر واحد مفصول بعلامات الجدولة، لتسهيل معالجته باستخدام أدوات سطر أوامر لينكس مثل `grep`, `awk`, `cut`, و `sed`.
3. **صيغة لغة التوصيف الموسعة (XML Output `-oX`):** ملف هيكلي مهيكل بلغة XML، وهو المعيار المفضل للاستيراد البرمجي في أدوات مثل Metasploit Framework (`db_import`)، منصات إدارة الثغرات مثل DefectDojo، وبرمجيات بايثون.
4. **صيغة السكربت كيدي (Script Kiddie Output `-oS`):** صيغة ترفيهية تحول النصوص إلى لغة الـ Leetspeak.
5. **حفظ كافة الصيغ في آن واحد (All Formats `-oA`):** ينشئ ثلاثة ملفات في نفس اللحظة تحمل نفس الاسم الأساسي بالامتدادات: `.nmap`, `.gnmap`, و `.xml`.

---

### 2. التفكير التحليلي المستقل (Stage B: Independent Analytical Thinking)

#### السؤال 1: المعامل المستخدم لحفظ المخرجات بصيغة قابلة للفلترة بـ grep:
* المعامل الذي يبدأ بـ `-o` (مختصر Output) متبوعاً بحرف يرمز لـ Greppable هو **`-oG`**.
* هذا الملف مفيد جداً لاستخراج كافة الأجهزة التي تمتلك منفذاً مفتوحاً معيناً بأمر واحد:
  `grep -i "80/open" target-scan.gnmap | cut -d ' ' -f 2`

#### السؤال 2: إمكانية حفظ مخرجات Nmap بصيغة XML:
* يوفر Nmap خيار `-oX` المخصص كلياً لإنشاء ملفات XML قياسية متوافقة مع مخططات DTD الرسمية.
* لذلك، فإن الإجابة على السؤال هي بالتأكيد نعم (**`yea`**).

---

### 3. التلميحات الموجهة (Stage C: Guided Hints)
* ابدأ المعامل بشرطة واحدة وحرف `o` صغير ثم الحرف الكبير `G` المشتق من كلمة Greppable: `-oG`.
* أجب بـ `yea` لتأكيد دعم Nmap لصيغة XML عبر المعامل `-oX`.

---

### 4. الحل العملي المفصل (Stage D: Complete Practical Solution)

#### أمثلة الأوامر الميدانية لحفظ النتائج:
```bash
# 1. حفظ المخرجات بالصيغة العادية
nmap -sV MACHINE_IP -oN scan-results.nmap

# 2. حفظ المخرجات بالصيغة القابلة للفلترة بـ grep
nmap -sV MACHINE_IP -oG scan-results.gnmap

# 3. حفظ المخرجات بصيغة XML
nmap -sV MACHINE_IP -oX scan-results.xml

# 4. الممارسة القياسية الفضلى: حفظ كافة الصيغ الثلاث دفعة واحدة
nmap -sV -sC -O MACHINE_IP -oA audit-report
```

### 5. الإجابات النموذجية المعتمدة (Stage E: Final Answers)
1. **السؤال 1:** What parameter is used to save the output in a greppable format? Write with a dash (-).
   * **الإجابة:** `-oG`
2. **السؤال 2:** Is it possible to save Nmap output in XML format (yea/nay)?
   * **الإجابة:** `yea`

### 7. المخرجات التعليمية والدروس المستفادة (Stage G: Educational Takeaway)
* الممارسة الفضلى الدائمة في اختبارات الاختراق هي الاعتماد الدائم على المعامل `-oA <filename>` في كل فحص تجريه؛ فالحصول على ملفات XML يمكنك من دمج النتائج مع قواعد بيانات Metasploit، بينما ملفات `.gnmap` تتيح لك كتابة سكربتات باش سريعة لفلترة الأهداف واستخراج عناوين الـ IP والمنافذ في أجزاء من الثانية.
