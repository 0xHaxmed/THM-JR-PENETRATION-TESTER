# Authoritative References: Module 15 Topic Transition Recap

## 1. Cross-Domain Standards & Benchmarks
- **MITRE ATT&CK Enterprise Matrix:**
  - URL: `https://attack.mitre.org/`
  - Structural hierarchy: Tactics, Techniques, Sub-techniques, and Procedures.
- **David J. Bianco: The Pyramid of Pain:**
  - URL: `https://detect-respond.blogspot.com/2013/03/the-pyramid-of-pain.html`
  - Evaluating detection difficulty across Hashes, IPs, Domains, Artifacts, Tools, and TTPs.
- **NIST SP 800-61 Rev 2: Computer Security Incident Handling Guide:**
  - Federal standards for the four-phase incident handling lifecycle.
- **NIST SP 800-218: Secure Software Development Framework (SSDF):**
  - Shifting security left across the automated software engineering lifecycle.
- **OWASP Top 10 for LLM Applications (2025 Edition):**
  - LLM01 (Prompt Injection), LLM07 (System Prompt Leakage), and RLHF generalization mismatch.
- **OWASP Mobile Application Security Verification Standard (MASVS v2.0):**
  - Mobile platform security standards and operating system sandboxing.
