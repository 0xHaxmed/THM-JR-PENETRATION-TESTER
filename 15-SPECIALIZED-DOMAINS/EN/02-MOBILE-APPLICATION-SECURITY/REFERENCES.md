# Authoritative References: Mobile Application Security

## 1. Industry Standards & Frameworks
- **OWASP Mobile Application Security Verification Standard (MASVS v2.0):**
  - Canonical URL: `https://mas.owasp.org/MASVS/`
  - Defines the baseline security controls for mobile apps across MASVS-STORAGE, MASVS-CRYPTO, MASVS-AUTH, MASVS-NETWORK, MASVS-PLATFORM, and MASVS-CODE.
- **OWASP Mobile Application Security Testing Guide (MASTG):**
  - Canonical URL: `https://mas.owasp.org/MASTG/`
  - The comprehensive manual for mobile app security testing, covering static and dynamic test cases for Android and iOS.
- **OWASP Mobile Top 10 (2024 Edition):**
  - Canonical URL: `https://owasp.org/www-project-mobile-top-10/`
  - Authoritative classification of the top 10 security risks facing mobile applications.

---

## 2. Platform Documentation
- **Android Developer Documentation: App Security Best Practices:**
  - URL: `https://developer.android.com/privacy-and-security/security-best-practices`
  - Guidance on permission scoping, exported components, and Keystore usage.
- **Android Network Security Configuration:**
  - URL: `https://developer.android.com/privacy-and-security/security-config`
  - Declarative configuration of network security and custom certificate trust anchors.
- **Apple Platform Security Guide:**
  - URL: `https://support.apple.com/guide/security/welcome/web`
  - In-depth technical architecture of iOS sandboxing, Secure Enclave, and hardware encryption.
- **Apple Developer: App Transport Security (ATS):**
  - URL: `https://developer.apple.com/documentation/security/preventing_insecure_network_connections`
  - Requirements for enforcing secure HTTPS network connections in iOS applications.
